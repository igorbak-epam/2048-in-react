# 2048 in React

A 2048 game in the browser: Next.js 14 (pages router), React 18, TypeScript.
The rules of the game live in `reducers/game-reducer.ts`; `context/` feeds
them to the components in `components/`; the tests are in `__tests__/`.

Install the dependencies once with `npm install`.

run: npm run dev
test: npm test
coverage: npm run coverage
